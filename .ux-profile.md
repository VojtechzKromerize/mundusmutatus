# UX Profile

Profil vkusu webu Mundus Mutatus pro UI/UX skills (VectorLab ux-audit a domény). Sepsáno 2026-11-02 podle `CLAUDE.md` › Konvence › Vzhled
a podle auditu UI z 2026-11-01. Skills čtou tento soubor před změnou rozvržení, stylů nebo textů rozhraní.

## Aesthetic reference

- **Standard:** Custom – středověká kronika / iluminovaný kodex
- **Notes:**
  - Web stránek a map: pergamen (`--paper`, `--bg`), inkoust (`--ink`), vínová kůže (`--kuze`), zlaté linky (`--zlato-linka`, `--gold`),
    iluminační modř; barvy vyznání `--kat` / `--kal` / `--mix`. Světlý i tmavý režim (`prefers-color-scheme` + `html[data-theme]`).
  - Hráčova karta a boj: tmavá karta ve stylu D&D Beyond s barevnými motivy `html[data-kb]` (proměnné `--kb-*`, `--kbt-*`), kontrast ≥ 4,5:1 hlídá
    `testy/jednotky/barvy-karty.test.mjs`.
  - Písma: nadpisy Grenze Gotisch (`--f-disp`), text Alegreya (`--f-body`), popisky Alegreya Sans SC (`--f-label`), podnadpisy Alegreya SC (`--f-nadp`).
  - Ozdoby kodexu **nejsou chyba**: zlaté rámy a vnitřní linky (`box-shadow: inset`), kožené přechody na tlačítkách a v záhlaví, iniciály, pečeti,
    rohové kování, erby, svíčka. Audit je posuzuje podle tohoto stylu, ne podle střídmosti Stripe/Linear.
  - Struktura zůstává čitelná: obsah na pergamenu, seznamy a tabulky s linkami, karta s jasnou hierarchií. Srozumitelnost pro hráče má přednost
    před historickou přesností.
  - Mobil (375–430 px) je hlavní zařízení hráčů; vypravěč hraje hlavně na PC (1280+), pult ale musí fungovat i na telefonu.

## Banned anti-aesthetics

- Glassmorphism a `backdrop-filter` (rozmazané průhledné panely)
- Duhové a neonové přechody, zářící neonové okraje, „SaaS“ pastelové štítky pro běžná metadata
- Kreslené ilustrace prázdných stavů (mávající postavičky), stock fotografie
- Moderní plochý „startup“ vzhled v rozporu s kodexem (bílé karty se stínem bez rámu, systémové bezpatkové písmo v obsahu)
- Nestylovaná šedá pole prohlížeče (základní vzhled polí je v `:where(input, select, textarea)` na konci `styly.css`)
- Vnořené posuvníky a ikony uvnitř polí
- Nová barevná emoji jako ikony rozhraní (stávající 🎲 ✉ 💡 se tolerují do přestavby; typografické znaky ✦ ☰ × ⚑ ◈ jsou v pořádku)

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** text ≥ 4,5:1, velký text a okraje ≥ 3:1 – i v tmavém režimu a ve všech motivech karty; zlatý text na pergamenu jen pro nadpisy
- **Touch / focus:** hlavní ovládací prvky ≥ 44 × 44 px na telefonu (odkazy v souvislém textu výjimkou); text rozhraní ≥ 11 px;
  viditelný `:focus-visible` (nikdy `outline:none` bez náhrady); `prefers-reduced-motion` ruší pohyb (zbývá jen průhlednost)

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric – vypravěčský, ale věcný
- **Capitalization:** Sentence case for UI copy and buttons (české texty mají velké jen první písmeno; kapitálky dělá písmo `--f-label`, ne text)
- **Notes:**
  - Celé rozhraní česky; hráči neumí latinu. Pojmy pravidel se zobrazují česky (`pojmyCz`), názvy kouzel a předmětů zůstávají anglicky,
    stavy česky s anglickým názvem v závorce.
  - Tlačítka začínají slovesem („Přidat“, „Hodit“, „Uložit“, „Nabídnout“); žádné „OK“, „Odeslat“, „Pokračovat“.
  - Chybové hlášky neobviňují hráče a říkají, co dál („Nepodařilo se uložit – zkus to znovu“); technický detail až za ní.
  - Lore, Kronika a popisy míst: kronikář Vojtěch z Kroměříže – čeština evokující 15. století, ale čtivá. Rozhraní (tlačítka, nápověda) píše
    současnou češtinou.
  - Mazání vždy s potvrzením, které jmenuje, co se maže („Smazat obchod U Kohouta?“).

## Icon library

- **Library:** Project SVG + project raster icons
- **Package / path:** `bi(k)` a `bdmIc()` (SVG symboly ve skriptu, 11-boj.js, 14-karty-bojova-karta.js); ikony účinků, mincí a stavů
  `art/img/boj/*-48.webp` / `*-96.webp`; erby `art/img/erby/`; žetony bestiáře `art/bestiar/`
- **Notes:** nové ikony kreslit ve stejném stylu (malované, zlatá/inkoustová linka, ne plochý outline set); nemíchat s Lucide, Heroicons a spol.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
6. Vizuální kontrolu dělej na statickém buildu (`python3 zdroj/build.py --staticky`, `--vypravec --staticky`) při 375 a 1280 px, světlý i tmavý režim – náhled dev nemusí být z prostředí dostupný.
